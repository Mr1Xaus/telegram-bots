# ПРАВИЛА БЕЗОПАСНОЙ РАБОТЫ С GIT (ANTI-DATA-LOSS)

При любой просьбе пользователя "закомить", "синхронизируй", "сохрани в гит" или "сделай пуш", ты обязан строго следовать этому алгоритму шаг за шагом. Твоя главная цель — не допустить потери локальных данных или перезаписи истории.

1. АБСОЛЮТНЫЙ ЗАПРЕТ: 
   - НИКОГДА не используй флаг --force или -f.
   - НИКОГДА не используй git reset --hard или git clean -fd. 
   - Если без них не обойтись — остановись и запроси явное разрешение пользователя.

2. РАЗВЕДКА (Fetch & Status):
   - Всегда начинай с команды git fetch origin.
   - Выполни git status и git log HEAD..origin/main (или текущей ветки), чтобы проверить, не отстает ли локальная ветка от удаленной.

3. БЕЗОПАСНОЕ СЛИЯНИЕ (Pull):
   - Если удаленная ветка ушла вперед И есть локальные незакомиченные изменения:
     а) Выполни git stash, чтобы спрятать изменения.
     б) Выполни git pull, чтобы скачать код.
     в) Выполни git stash pop, чтобы вернуть изменения.
     г) Если возник конфликт при pop — НИЧЕГО не коммить, покажи список конфликтующих файлов и жди указаний.

4. СОХРАНЕНИЕ И ОТПРАВКА (Commit & Push):
   - Если конфликтов нет, добавь файлы: git add .
   - Сделай коммит: git commit -m "Auto-sync: Добавлены системные правила агента"
   - Отправь код: git push

5. ОТЧЕТ:
   - Выведи короткое сообщение: "Успешно синхронизировано. Изменены файлы: [список]".
