# Telegram Bots Repository

Репозиторий для хранения и разработки Telegram-ботов. 
Проект организован по принципу монорепозитория, где каждый бот располагается в своей отдельной директории внутри папки `bots/`.

---

## 📁 Структура репозитория

```text
telegram-bots/
├── .gitignore              # Игнорируемые файлы (секреты, venv, кэш)
├── README.md               # Документация репозитория
└── bots/                   # Папка со всеми подпроектами ботов
    └── first_bot/          # Первичный шаблон/проект бота
        ├── .env.example    # Пример переменных окружения
        ├── .env            # Переменные окружения (локальные секреты)
        ├── config.py       # Загрузка и валидация конфигурации
        ├── requirements.txt # Зависимости Python (aiogram 3.x)
        ├── main.py         # Точка входа для запуска бота
        ├── handlers/       # Обработчики команд и сообщений
        └── README.md       # Инструкция по запуску конкретного бота
```

---

## 🚀 Добавление нового бота

Чтобы добавить новый бот в репозиторий:

1. Создайте новую папку в директории `bots/`, например `bots/my_new_bot/`.
2. Скопируйте структуру из `bots/first_bot/` или создайте свой проект.
3. Каждая папка бота содержит свои зависимости, настройки `.env` и точку входа `main.py`.

---

## 🔒 Безопасность

* Никогда не коммитьте файлы `.env` с реальными токенами ботов.
* Используйте файл `.env.example` для демонстрации необходимых ключей окружения.
